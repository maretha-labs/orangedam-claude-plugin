# Security and Support

`maretha-orangedam-config` (OrangeDAM Config Assistant by Maretha) v1.0 is a public engineering plugin built from Markdown skills, plain-text templates, and standard-library Python 3 validation scripts. It includes no remote MCP server, makes zero outbound network calls, and collects no credentials.

## Reporting a Vulnerability

Please report suspected security or prompt-safety vulnerabilities privately through [https://maretha.io/contact](https://maretha.io/contact) (or via [GitHub Private Vulnerability Reporting](https://github.com/maretha-labs/orangedam-claude-plugin/security/advisories/new)).

Do **not** include credentials, client documents, or sensitive logs in public GitHub issues.

## Safe Usage

- Use synthetic data for initial evaluation and never paste live API keys, passwords, or OAuth secrets into sample CSVs.
- Always test generated OrangeDAM permissions, Security Functions, and workflows using dedicated Test Impersonation Accounts in a non-production Sandbox before applying changes to Production.
- Commercial implementation support, if required, is agreed separately via [https://maretha.io/contact](https://maretha.io/contact).
