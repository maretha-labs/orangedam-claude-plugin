# Support — OrangeDAM Config Assistant by Maretha

## Getting Help

- **Bug reports & feature requests:** Open an issue on [GitHub Issues](https://github.com/maretha-labs/orangedam-claude-plugin/issues) (redact any confidential data or credentials).
- **Private & commercial inquiries:** Contact Maretha via [https://maretha.io/contact](https://maretha.io/contact).
- **Security vulnerabilities:** Report privately via [https://maretha.io/contact](https://maretha.io/contact) or [GitHub Private Vulnerability Reporting](https://github.com/maretha-labs/orangedam-claude-plugin/security/advisories/new).

## Scope of Support

This repository is an open-source partner resource for configuring OrangeDAM. For Orange Logic platform bugs, tenant provisioning, or official product documentation, contact Orange Logic Support through your organization's Link portal. Commercial implementation services are agreed separately.
