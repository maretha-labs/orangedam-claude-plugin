# Privacy Policy — OrangeDAM Config Assistant by Maretha

Effective Date: 2026-11-24

## 1. Data Collection

Version 1.0 of `maretha-orangedam-config` ("OrangeDAM Config Assistant by Maretha") operates solely as local Markdown instructions, plain-text templates, and standard-library Python 3 validation scripts executed inside your Claude environment.

- **No external transmission:** This plugin makes zero outbound network requests and connects to no remote MCP servers or analytics endpoints controlled by Maretha.
- **No personal data collection:** Maretha does not receive, collect, store, or process your conversation transcripts, configuration CSVs, metadata schemas, or user lists.
- **No credential handling:** This plugin does not request, read, or transmit passwords, API keys, or OAuth tokens.

## 2. Usage & Storage

Any files generated or validated by the plugin exist exclusively inside your Claude session or local workspace under Anthropic's or your organization's own data-handling policies.

## 3. Third-Party Sharing

Maretha shares no user data with third parties because Maretha collects no user data from this plugin.

## 4. Data Retention

Maretha retains zero user data from plugin execution. Aggregate directory install and usage metrics provided to publishers by Anthropic's Developer Portal contain no user-identifiable content.

Questions or privacy inquiries: [https://maretha.io/contact](https://maretha.io/contact).
